Island Tacos — Local Server Setup Guide

Complete step-by-step installation for your Windows mini PC. No IT knowledge required.

1 Download & Extract the Island Tacos Software

This single command downloads and extracts everything automatically. Copy and paste it — don't type it by hand.

  • Click the Windows Start button, type "PowerShell", right-click it, and choose "Run as administrator" A blue window will open. Click Yes if Windows asks for permission.
  • Copy the line below exactly, paste it into the blue PowerShell window, and press Enter
    New-Item -ItemType Directory -Force C:\IslandTacos | Out-Null; Invoke-WebRequest -Uri "https://orders.islandtacosbvi.com/island-tacos-installer.tar.gz" -OutFile "$env:TEMP\it.tar.gz"; tar -xzf "$env:TEMP\it.tar.gz" -C C:\IslandTacos --strip-components=1
    This downloads the latest software and extracts it to C:\IslandTacos. It may take 1–2 minutes depending on your internet speed.
  • When the command finishes (the cursor returns to a new line), you can close PowerShell You will run the actual installer in the next step.
💡 Result You should now have a folder at C:\IslandTacos containing files like INSTALL.bat, INSTALL.ps1, package.json, and folders named artifacts, lib, etc.
2 Run the Installer

This installs everything automatically — Node.js, the database, the app, and more.

  • Open the folder C:\IslandTacos in File Explorer Press the Windows key, type "File Explorer", open it, then navigate to C:\IslandTacos.
  • Find the file called INSTALL.bat It has a small gear or terminal icon. If you don't see it, make sure you're inside the IslandTacos folder.
  • Right-click INSTALL.bat → click "Run as administrator" Windows may ask "Do you want to allow this app to make changes?" — click Yes. This is required for installation.
  • A black window will open with a blue Island Tacos banner. Press Enter to begin. The installer will now check your computer and begin installing required software. This may take 2–5 minutes.

4 Set Up Tailscale — Access from Anywhere

Tailscale lets you open the admin panel from your phone or laptop even when you're not at the restaurant. It's free.

💻
On the mini PC — go to tailscale.com/download and click "Download for Windows"

Install it just like any other program. Double-click the installer and click through the steps.

🔑
When Tailscale opens, click "Log in" and create a free account

Use your email address. You'll need to remember this login for the next step.

📱
On your phone — download the Tailscale app (iPhone: App Store / Android: Play Store)

Search for "Tailscale". It's the blue app with a white icon. It's free.

🔗
Open Tailscale on your phone and log in with the same account you used on the mini PC

Both devices will now appear in your Tailscale network.

🌐
In the Tailscale app on your phone, tap on the mini PC to see its Tailscale IP address

It will look like 100.xx.xx.xx. Write it down.

✅
From anywhere with internet, open a browser and go to http://100.xx.xx.xx:3001

Replace 100.xx.xx.xx with your actual Tailscale IP. This is your remote access address. Bookmark it.

💡 You now have two addresses for the admin: At the restaurant (WiFi): http://192.168.x.x:3001  (faster)
From anywhere: http://100.xx.xx.xx:3001  (Tailscale address)
5 Connect the Online Store (One-Time Setup)

This lets your local admin push menu changes to orders.islandtacosbvi.com. You only do this once.

  • On any device, go to replit.com and open your Island Tacos project
  • Look for the lock icon (🔒) in the left sidebar — click it to open Secrets This is where Replit stores passwords safely.
  • Click "New Secret" and fill in the following: Key: SYNC_SECRET    Value: the Sync Secret password you wrote down in Step 3
  • Click "Add Secret" to save it Replit will automatically use this the next time the online store is restarted.
  • Restart the Replit app by clicking the Stop button then the Run button This activates the new secret on the cloud server.
✅ To test the sync: Go to your local admin panel → the Sync Menu to Online Store card is at the top of the dashboard. Click Sync Now. You should see "Synced!" in green within a few seconds.
6 Set Up Your Tablets and Kitchen Screen

Do this on every tablet and screen you use in the restaurant.

  • Make sure the tablet is connected to the restaurant WiFi (same network as the mini PC)
  • Open Chrome (or Safari on iPad) and type the local server address in the address bar Example: http://192.168.1.50:3001 — use the address shown at the end of your installer.
  • For POS tablets: go to /it-admin in the browser and log in, then navigate to POS Example: http://192.168.1.50:3001/it-admin
  • For the Kitchen Screen (KDS): go to /it-admin/kitchen Tap the three dots in Chrome → "Add to Home Screen" to create a shortcut. It will open full-screen like an app.
  • Repeat for each device
7 Set Up Receipt Printing

The mini PC talks directly to your receipt printer over WiFi — no extra software needed.

  • On any POS tablet, open the POS and log in
  • Look for the Printer Settings button (🖨) in the top-right corner of the POS
  • Set Print Mode to "Network ESC/POS"
  • Enter your printer's IP address This is likely 192.168.8.195 — or whatever you entered during installation.
  • Click Save, then try printing a test receipt

🔧 Troubleshooting

If something isn't working, try these fixes first.

The app won't open on a tablet Make sure the tablet and the mini PC are on the same WiFi network. Check that the mini PC is turned on. Try the address again — make sure you typed it exactly right including http:// at the start.
The printer isn't printing Make sure the printer is on and connected to WiFi. Double-check the printer IP address in POS → Printer Settings. Make sure you selected "Network ESC/POS" as the print mode (not Bridge or Browser).
Sync Now shows an error Make sure the SYNC_SECRET you added to Replit Secrets exactly matches the Sync Secret you entered during installation (same spelling, same capitalization). Restart the Replit app after adding the secret.
After a power outage, the app takes a minute to come back This is normal. The mini PC is rebooting and the server is starting up automatically. Wait about 60 seconds after the mini PC's screen lights up, then try again.
Still stuck? Open a web browser on the mini PC and go to http://localhost:3001. If the app loads, the server is running fine — the issue is with network access on the tablet. If it doesn't load, the server may have stopped — open a Command Prompt (search "cmd" in the Start menu) and type: pm2 restart island-tacos and press Enter.
