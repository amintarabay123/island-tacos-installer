Staff PINs & Authentication

Keep this page secure. These PINs grant access to your POS, admin panel, and financial data.

Used by: Cashiers, kitchen staff
Grants access to POS and Kitchen Display. Stored as secret STAFF_PIN in Replit.

Admin PIN
Used by: Manager / Owner

Receipt Printing

Two printing methods are supported. Configure in Admin → Settings → Printer.

Option A — Browser Print (Default)
Opens a print dialog in the browser
Works on any device. Good for desktop or iPad POS setup. No extra hardware config needed.
Option B — Network Thermal Printer
Sends ESC/POS commands over TCP
Requires a network-connected thermal printer. Set the printer's IP address in Settings. Printer must be on the same network as the POS device. Default port: 9100.

Network Printer Setup

1
Connect your thermal printer to the Wi-Fi network
2
Print a test page from the printer to find its IP address
3
In the POS app go to Admin → Settings → Printer, select "Network Printer", enter the IP address
4
Click "Test Print" to verify — a receipt should print immediately

Email Receipts

In the POS Receipts drawer, tap ✉ Email on any completed order. If the customer's email is on file it pre-fills automatically; otherwise type it in and tap Send. Receipt arrives from orders@islandtacosbvi.com.

POS Daily Workflow

Opening the Register

1
Open the POS on your device, enter your staff PIN
2
If no shift is open, the Open Shift modal appears — count your cash drawer and enter the opening float, then click Open
3
POS is ready. Online orders appear automatically in the Orders drawer

Taking an Order

1
Select items from the menu grid (left side). Tap item to add to cart.
2
Adjust quantity with +/− buttons. Apply discount if needed.
3
Tap Charge → select payment method → complete payment
4
Receipt prints / email sent if customer provided email

Handling Online Orders

1
New online orders appear in the Orders drawer (bell icon) with a "New" badge
2
Tap Accept — customer's tracking page updates to "Accepted"
3
Tap Start Cooking when you begin preparing
4
Tap Mark Ready when order is at the pickup counter
5
Tap Charge to complete and close the order

Closing the Register

1
Tap the shift/register icon in the POS header → Close Shift
2
Count your cash drawer and enter the closing amount
3
Review the Z-report (total sales, by method, pay-ins/outs, expected cash)
4
Print the Z-report if needed, then close the shift

Issuing a Refund

1
Open the Receipts drawer in POS (receipt icon)
2
Find the order, tap ↩ (refund button)
3
Enter refund amount, method, and reason → confirm

Emergency Reference

Something broken? Use this section to quickly diagnose and recover.
ProblemFirst thing to try
Orders not appearing in POS Hard-refresh the browser (Ctrl+Shift+R / Cmd+Shift+R). Check internet connection. Check Replit deployment status.
Customer can't place order online Try opening order-direct-connect.replit.app directly (bypasses custom domain). Check if the item is marked available in Menu Management.
ATH Móvil payments not confirming Check ATH Móvil Business dashboard for payment status. Verify webhook URL is registered: https://order-direct-connect.replit.app/api/athmovil/webhook.
Email receipts not sending Check Google Workspace orders@ account — 2FA must be on. Regenerate App Password if needed and update SMTP_PASSWORD in Replit Secrets.
Printer not printing Check printer is on and connected to same Wi-Fi. Confirm IP address in Admin → Settings. Try switching to Browser Print as a fallback.
Custom domain not loading Use order-direct-connect.replit.app — it always works. Custom domain is cosmetic and DNS verification may still be pending.
Admin login not working Check your email for the Clerk OTP code (check spam). If PIN prompt: confirm PIN with owner. Try incognito/private browser window.
App showing old version Clear browser cache or open in incognito. The PWA service worker may be caching — unregister it in browser DevTools → Application → Service Workers.
